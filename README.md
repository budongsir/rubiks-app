# 魔方 3D 还原助手

基于 Next.js 的魔方还原应用，支持通过摄像头扫描魔方各面，并提供直观的 3D 分步还原指引。

## 技术栈

Nextjs, React, Threejs, Framer-motion, Gsap, Shadcn/ui, Typescript, Tailwindcss
